# ZFB Pharmaceuticals

---

## About ZFB Pharmaceuticals

**ZFB Pharmaceuticals** is a professional pharmaceutical website focused on presenting healthcare products and pharmaceutical solutions through a modern, responsive, and user-friendly digital platform.

The website provides visitors with clear access to:

* Pharmaceutical products
* Fertility healthcare
* Women's health
* Men's health
* Nutraceuticals
* Therapeutic healthcare categories
* Company information
* Professional team information
* Product details
* Contact and enquiry information

---

## Key Features

### Pharmaceutical Product Catalogue

A dedicated product section for presenting pharmaceutical products with:

* Product images
* Product names
* Product categories
* Product descriptions
* Product details
* Product filtering
* Interactive product cards

### Fertility Healthcare

Dedicated presentation of fertility and reproductive healthcare solutions.

### Women's Health

Healthcare products and solutions focused on women's health.

### Men's Health

Dedicated category for men's healthcare and reproductive wellness.

### Nutraceuticals

Presentation of nutritional and wellness-focused healthcare products.

### Product Filtering

Users can easily browse products according to different therapeutic categories.

### Cart System

The website includes a cart interface for selecting pharmaceutical products and managing product enquiries.

### Fully Responsive

The website is designed for:

* Desktop
* Laptop
* Tablet
* Mobile devices

### Modern Pharmaceutical UI

The website uses a clean and professional interface with:

* Modern product cards
* Responsive layouts
* Interactive elements
* Product detail popups
* Smooth animations
* Professional healthcare styling

# Getting Started

## Clone the Repository

```bash
git clone https://github.com/mansoorkhoshal/zfb-pharmaceuticals-website.git
```

## Open the Project

```bash
cd zfb-pharmaceuticals-website
```

## Run Locally

This is a static HTML, CSS, and JavaScript website.

You can open:

```text
index.html
```

directly in your browser.

For the best development experience, open the project in **Visual Studio Code** and use the **Live Server** extension.
